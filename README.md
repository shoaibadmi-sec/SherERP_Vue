# SherERP Vue

SherERP is a NestJS/Vue TypeScript ERP monorepo for shop management. This repository contains a source snapshot recovered from a local WSL project backup dated September 9, 2026, including working-tree changes. Machine-specific credentials, private environment files, and generated local artifacts are excluded.

## Structure

- `apps/web`: Vue frontend
- `apps/api`: NestJS API
- `apps/admin`: administration UI
- `apps/control-plane`: control plane
- `packages`: domain, application, contracts, adapters and utilities
- `migrations`: database migrations
- `docs`: specifications and testing documentation

See `AGENTS.md`, `SRS_AND_BUILD_GUIDE.md`, and `docs/CURRENT_STATE.md` for context. The original backup has been left unchanged.
